# IBS Project

This repository contains experimental code for the IBS Reticulotype project.

## Integrations

The project demonstrates how to interface with several external services:

- **HuggingFace phi-2**: used for generating explanations.
- **HL7 FHIR**: retrieves patient information from a test FHIR server.
- **PubMed E-Utilities**: searches PubMed for related articles.
- **OpenAI Function Calling**: allows multi-agent coordination via ChatGPT.
- **Neo4j Graph Queries**: records and queries patient evolution paths.
